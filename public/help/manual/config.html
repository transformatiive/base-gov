Configuração e perfis

Um perfil de atividade = palavras-chave + códigos CPV + agenda de recolha.

  1. Crie um perfil por linha de negócio. Sem perfil, o Hoje não tem radar.
  2. No registo o perfil nasce com agenda diária. Pode mudar para semanal ou manual.
  3. Para dispositivos médicos, use CPV 331 — o radar privilegia equipamento, não obras hospitalares.
  4. Recolhas do site e dados abertos são avançados; a maior parte das empresas usa só o perfil.

A edição do perfil de atividade (PUT) ainda não existe: apague e crie de novo se precisar de corrigir termos.
